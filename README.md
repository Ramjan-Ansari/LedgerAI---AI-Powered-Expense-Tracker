# 💰 LedgerAI – AI-Powered Expense Tracker

LedgerAI is a full-stack AI-powered personal finance management application built with the PERN stack (PostgreSQL, Express.js, React.js, and Node.js). It enables users to efficiently manage their income, expenses, budgets, and financial goals while leveraging Google Gemini AI to generate intelligent spending insights, savings recommendations, and personalized financial reports. The application combines secure authentication, real-time analytics, interactive dashboards, and AI-driven recommendations within a modern, responsive user interface.

---

# ✨ Key Features

## 🔐 Secure Authentication
- Secure user registration and login
- JWT-based authentication
- Password hashing with bcrypt
- Protected routes and authorization

## 📂 Smart Category Management
- 17 default income and expense categories automatically created during registration
- Create custom categories
- Customize category icons and colors
- Edit and delete categories

## 💳 Transaction Management
- Add income and expense transactions
- Edit and delete transactions
- Search transactions
- Filter by category, date, type, and keyword
- Advanced transaction management

## 💰 Budget Management
- Create monthly and weekly budgets
- Track spending against budgets
- Real-time budget progress
- Budget status monitoring

## 📊 Interactive Dashboard
- Financial summary cards
- Monthly income vs expense trends
- Category-wise spending breakdown
- Recent transaction history
- Budget overview

## 📈 Advanced Analytics
- Switch between:
  - Last 30 Days
  - Last 3 Months
  - Monthly
  - Yearly
- Instant client-side aggregation
- Financial trend visualization

## 🤖 AI-Powered Insights (Google Gemini)
- AI Monthly Financial Summary
- Financial Health Score
- Personalized Recommendations
- AI Savings Tips
- Budget Performance Analysis
- Spending Behavior Analysis
- Filter-aware AI Insights
- Historical AI Reports

## 💾 AI Insight History
- Store every AI response in PostgreSQL JSONB
- View previous AI-generated reports anytime

## 🎨 Modern User Interface
- Fully Responsive Design
- Violet-themed UI
- Interactive Dashboard
- Animated Hero Section
- Paginated Transaction Management
- Gradient Charts
- Loading Skeletons
- Clean User Experience
